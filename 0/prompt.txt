# Product vision
PaperCI watches new arXiv papers, tries to run each paper's public code in a sandbox,
checks the paper's headline numeric claims with an independent verifier, and emits
(1) a reproducibility report with evidence + confidence label and
(2) a packaged, verified, executable task (Dockerfile + instruction + hidden verifier +
metadata) usable to evaluate or train agents. Think "CI for arXiv".
Scope: code papers, CPU-only, runs in minutes. Anything else is a roadmap slide, not code.
Positioning: contamination-free (fresh papers), independently verified tasks.
Results go to our own registry. An opt-in "review my paper" page may be MOCKED only.
Verdict labels: verified | falsified-candidate | toy-scale | inconclusive | blocked-infra.
Pipeline: watcher -> triage/gate -> sealed claim extraction -> builder (recovers from
failures) -> independent verifier -> robustness (reruns, seeds, tolerance calibration)
-> packager (Harbor/Terminal-Bench-style layout; confirm the schema from its docs)
-> trainability filter (cheap solver, keep tasks it solves sometimes) -> registry/dashboard
with funnel stats and cost per verified task.

# Non-negotiable engineering principles
1. Claims are SEALED: store and hash them; the builder/solver must never see claim values.
2. The verifier is independent: reads only run artifacts, deterministic comparison first,
   LLM only for qualitative claims and from a different model family than the builder.
3. Anti-cheat: detect hardcoded numbers, prebuilt result files, unexpected network egress.
4. Stage isolation + persisted state (SQLite) so a crash resumes instead of restarting.
5. Real recovery: install/version/data/timeout failures must be handled and visible in traces.
6. Keep a DEV paper set and a separate HELD-OUT set. Improve against dev only; report
   before/after on held-out. Never report numbers you did not measure.
7. Prefer your own simple tool-calling loop in Python (plus typed outputs, e.g. Pydantic)
   over heavy frameworks, so every model/tool call is traced. Do not adopt a harness that
   neatlogs cannot trace.
